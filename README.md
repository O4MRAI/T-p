# هسيس تشرين 🍂

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/O4MRAI/T-p)

غرفة ثلاثية الأبعاد (Three.js) لشخص يحب الكتب: أربع مكتبات خشبية مليئة بالكتب، نافذة على ليلة مقمرة، كرسي قراءة، مصباح وشمعة، وسرير على شكل سيارة فورمولا.

## تجربة هسيس تشرين

ورقة افتتاحية وفهرس للأركان الـ13، مع واجهة عربية بطابع ورقي عتيق وألوان عاجية وحبر بني، ومداخل داخل الغرفة. يدعم النموذج إضافة النصوص والصور والفيديو والصوت، تنظيم الكتب وحالات القراءة، المهام والعادات، وجورنال متعدد الصفحات بقصاصات قابلة للتحريك والتكبير.

**هذه نسخة مؤقتة:** إضافات الأركان تختفي عند تحديث الصفحة؛ لا تحتاج حسابًا أو إعداد خادم خلفي. كلمات الأبواب قابلة للتجاوز بزر «دخول تجريبي سريع». حفظ الكتب القديم داخل الغرفة ما زال يعمل كما كان. تفاصيل النطاق والقيود في [مرجع النسخة التجريبية](docs/world-prototype.md).

## المزايا
- **٤ مكتبات** بخمسة رفوف لكلٍّ منها، وعلى كل رف كتب بأحجام وألوان وعناوين مختلفة (روايات، مجلدات موسوعات، كتب ممددة فوق بعضها).
- **كل كتاب قابل للضغط**: عند المرور عليه يبرز قليلاً من الرف ويظهر عنوانه، وعند الضغط يطير نحوك ويُفتح.
- **الكتابة داخل الكتاب**: صفحتان متقابلتان (صفحة واحدة على الجوال) مع قلب الصفحات، ويمكن تغيير عنوان الكتاب أيضاً.
- **حفظ تلقائي** في المتصفح (`localStorage`)، والكتب التي فيها كتابة يظهر على كعبها شريط أحمر.
- تنزيل محتوى أي كتاب كملف نصي.
- **ثعلب واقعي يلعب**: يطارد كرة حمراء ويدفعها بخطمه، ويتمشى ويأكل ويتلفّت، وأحياناً يستلقي أو يجلس ليرتاح. اضغط على الكرة لتركلها.
- **سيارة فورمولا**: نموذج جاهز لسيارة مرسيدس W13 Concept كاملة بألوانها وإطاراتها الأصلية. وإذا تعذّر تحميل النموذج يُستخدم سرير على شكل سيارة مرسومة بالكود بتفاصيل كثيرة: هيكل انسيابي بطلاء لامع يعكس الغرفة، جناح أمامي وخلفي بمقاطع هوائية حقيقية، إطارات بكتابة على الجوانب وجنوط وأقراص فرامل، تعليق، مرايا، ناشر خلفي وضوء مطر يومض، فرشة ولحاف بعلم الشطرنج ومخدة، مع ملصق حلبة وخوذة.

## التشغيل
الصفحة تحمّل صوراً من مجلد `assets/`، لذلك شغّلها عبر خادم محلي (فتح الملف مباشرة لا يعرض الأرضية والمنظر الخارجي):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التحكم
| الإجراء | الطريقة |
|---|---|
| التجوّل في الغرفة | اسحب بالفأرة / بالإصبع |
| الاقتراب | عجلة الفأرة أو قرص الإصبعين |
| فتح كتاب | اضغط عليه |
| إغلاق الكتاب | زر ✕ أو `Esc` |
| حفظ فوري | `Ctrl + S` (والحفظ تلقائي أصلاً) |
| قلب الصفحات | أزرار التالي/السابق أو `Alt + ←/→` |
