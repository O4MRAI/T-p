# غرفة القارئ 📚

غرفة ثلاثية الأبعاد (Three.js) لشخص يحب الكتب: أربع مكتبات خشبية مليئة بالكتب، نافذة على ليلة مقمرة، كرسي قراءة، مصباح وشمعة، وسرير على شكل سيارة فورمولا.

## المزايا
- **٤ مكتبات** بخمسة رفوف لكلٍّ منها، وعلى كل رف كتب بأحجام وألوان وعناوين مختلفة (روايات، مجلدات موسوعات، كتب ممددة فوق بعضها).
- **كل كتاب قابل للضغط**: عند المرور عليه يبرز قليلاً من الرف ويظهر عنوانه، وعند الضغط يطير نحوك ويُفتح.
- **الكتابة داخل الكتاب**: صفحتان متقابلتان (صفحة واحدة على الجوال) مع قلب الصفحات، ويمكن تغيير عنوان الكتاب أيضاً.
- **حفظ تلقائي** في المتصفح (`localStorage`)، والكتب التي فيها كتابة يظهر على كعبها شريط أحمر.
- تنزيل محتوى أي كتاب كملف نصي.
- **ثعلب واقعي يلعب**: يطارد كرة حمراء ويدفعها بخطمه، ويتمشى ويأكل ويتلفّت، وأحياناً يستلقي أو يجلس ليرتاح. اضغط على الكرة لتركلها.
- **سيارة فورمولا**: نموذج جاهز لسيارة فيراري F2008 كاملة بألوانها وإطاراتها الأصلية. وإذا تعذّر تحميل النموذج يُستخدم سرير على شكل سيارة مرسومة بالكود بتفاصيل كثيرة: هيكل انسيابي بطلاء لامع يعكس الغرفة، جناح أمامي وخلفي بمقاطع هوائية حقيقية، إطارات بكتابة على الجوانب وجنوط وأقراص فرامل، تعليق، مرايا، ناشر خلفي وضوء مطر يومض، فرشة ولحاف بعلم الشطرنج ومخدة، مع ملصق حلبة وخوذة.

## التشغيل
الصفحة تحمّل صوراً من مجلد `assets/`، لذلك شغّلها عبر خادم محلي (فتح الملف مباشرة لا يعرض الأرضية والمنظر الخارجي):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التحكم
| الإجراء | الطريقة |
|---|---|
| التجوّل في الغرفة | اسحب بالفأرة / بالإصبع |
| الاقتراب | عجلة الفأرة أو قرص الإصبعين |
| فتح كتاب | اضغط عليه |
| إغلاق الكتاب | زر ✕ أو `Esc` |
| حفظ فوري | `Ctrl + S` (والحفظ تلقائي أصلاً) |
| قلب الصفحات | أزرار التالي/السابق أو `Alt + ←/→` |
